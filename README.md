# 🐍 Змейка

Классическая игра «Змейка» на чистом **HTML, CSS и Vanilla JavaScript**. Без фреймворков, сборщиков и зависимостей — достаточно открыть `index.html` в браузере.

Помимо базового геймплея в игре есть внутриигровая валюта, возрождение после столкновения и магазин скинов.

## 🎮 Возможности

- **Классический геймплей** — управляй змейкой, собирай еду и расти
- **Нарастающая сложность** — с каждой съеденной едой змейка ускоряется
- **Монетки** — за каждую съеденную единицу еды начисляется 1 монетка, баланс сохраняется между сессиями
- **Возрождение** — при столкновении за 10 монеток можно продолжить игру, сохранив длину змейки
- **Магазин скинов** — 8 скинов с 4 уровнями редкости, цена каждого — 10 монеток
- **Рекорды** — лучший счёт сохраняется автоматически
- **Адаптивный интерфейс** — шапка со статистикой, оверлеи, модальное окно магазина и анимации

## 🕹️ Управление

| Клавиша | Действие |
|---------|----------|
| `W` `A` `S` `D` / `↑` `↓` `←` `→` | Движение |
| `Пробел` | Старт / пауза |
| Клик по полю | Старт / пауза |

## 🎨 Скины

| Редкость | Скины |
|----------|-------|
| 🟢 Обычный | Классика |
| 🔵 Редкий | Огненная, Ледяная |
| 🟣 Эпический | Неоновая, Золотая |
| 🌟 Легендарный | Теневая, Радужная, Космическая |

Скины покупаются в магазине (кнопка 🛒 в шапке). Купленный скин можно выбрать в любой момент — выбор запоминается.

## ⚙️ Игровые параметры

Все значения задаются константами в начале `scripts/script.js` и легко настраиваются:

| Константа | Значение | Описание |
|-----------|----------|----------|
| `GRID_COUNT` | `20` | Размер поля в клетках (20×20) |
| `CANVAS_SIZE` | `400` | Размер холста в пикселях |
| `INITIAL_SPEED` | `150` | Начальный интервал между ходами, мс |
| `SPEED_INCREMENT` | `2` | На сколько мс ускоряется змейка после каждой еды |
| `MIN_SPEED` | `60` | Минимальный интервал между ходами (максимальная скорость), мс |
| `REVIVE_COST` | `10` | Стоимость возрождения в монетках |
| `SKIN_COST` | `10` | Стоимость скина в монетках |

## 🚀 Запуск

**Способ 1.** Скачайте или клонируйте репозиторий и откройте `index.html` в любом современном браузере. Сервер не нужен.

```bash
git clone https://github.com/Zosvex/Snake.git
cd Snake
```

**Способ 2.** Если хотите запустить через локальный сервер:

```bash
# Python 3
python -m http.server 8000
# затем откройте http://localhost:8000
```

## 💾 Хранение данных

Все данные хранятся в `localStorage` браузера:

| Ключ | Описание |
|------|----------|
| `snakeHighScore` | Лучший счёт |
| `snakeCoins` | Количество монеток |
| `snakeSkins` | Список купленных скинов |
| `snakeCurrentSkin` | Выбранный скин |

Чтобы сбросить прогресс, очистите данные сайта в браузере или выполните в консоли `localStorage.clear()`.
